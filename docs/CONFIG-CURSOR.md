# Cursor 对接文档 · 单学科教育智能体（数电）

> 本文件是 **Cursor 进入本项目的唯一导航入口**。  
> **竞赛提交范围**：只做 **学生端 + 管理端**。教师/考务端已砍掉。权威范围见 `docs/产品范围-学生端与管理端.md`。

## 0. 你在做什么项目

面向**数字电子技术**的助学智能体（揭榜挂帅参赛作品）。

一句话：**借通用大模型能力，做懂数电的问答/搜题/解题助手 + 学情自适应练习；管理端维护题库与回流审核。**

## 1. 必须遵守的底线

1. **范围**：学生端（问答、学情、错题本、自适应练习）+ 管理端（题库、回流、学情总览）。**禁止**恢复组卷/统考/收卷/改判/考务 Agent。
2. **Agent**：学生端一个助学 ReAct；管理端以表单操作为主，**无考务悬浮球**。
3. **界面即路由**：用户在哪个界面调哪个能力，不做巨型总调度。
4. **题库 = 管理端可维护资产**：学生只读；回流入库需校验/审核。
5. **信任分级**：题库命中=权威；AI 现解须标注「仅供参考」。
6. **隐私**：对话摘要仅学生可见；管理端可读学情画像，不可读摘要原文。
7. **冲突裁决**：`产品范围-学生端与管理端.md` > 本文件 > 旧宪法中师生双端表述。
