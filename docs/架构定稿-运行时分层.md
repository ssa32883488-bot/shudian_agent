# 运行时分层定稿（决策记录）

> 状态：**已定稿**（2026-09-07）  
> 范围：助学 Agent 运行时；与「统一决策者 / 题库匹配 / ≤3 轮自研 / 三层记忆 / 五类工具」一并生效。

---

## 1. 一句话

感知出题面 → 规划/推理（决策者）做意图与回判 → 编排按计划调工具 → **护栏与可观测横切**；过关才交付。

---

## 2. 四层职责（定稿）

| 层 | 职责 | 不做 |
|----|------|------|
| **感知层** | 文本/图片/附件 → `question_text`、`source`、是否含图、**题量粗估**等 | 同一性判断、选工具、写最终答案 |
| **规划/推理层** | 统一决策者：意图、计划、对工具结果回判；自研回环 **≤3** | 具体绘图实现、向量检索细节 |
| **编排层** | 按 `plan.steps` 调度工具与子流程；更新 State / Checkpointer | 擅自把检索结果标成权威答案；跳过回判 |
| **护栏与可观测性** | 断路器 + 轨迹/指标；可打断编排 | 默认不改写学科结论正文 |

**边界**：感知不做「是否同一道题」；规划不做落地画图；编排不宣布权威；护栏保活与可审计。

---

## 3. 已确认细则

### 3.1 题量裁剪

- **感知**：仅**粗估**（多题/整卷信号）。  
- **编排**：规划含 `scope` 时再执行裁剪（只详解前 N 道并提示用户）。

### 3.2 绘图校验（双保险）

1. **工具内**：绘图工作流内置循环校验。  
2. **规划层**：工具结果仍回决策者，终判「图 + 解题理解是否满足需求」；不满足则再规划（计入 ≤3 轮）。

### 3.3 可观测性（都要）

| 受众 | 形态 |
|------|------|
| **学生端** | 步骤条 / status（决策规划、执行中的工具步、评审中等） |
| **管理端** | 完整 trace（Thought→Action→Observation、匹配分、评审分、熔断原因、轮次） |

---

## 4. 与旁挂层关系（不变）

- **记忆**：短期 State+Checkpointer；长期按需 Tool；学情后台异步画像。  
- **工具**：题库、课本、知识图谱、绘图工作流、长期记忆读写。  
- **交付**：匹配通过 → 权威；自研过评审 → AI 参考；否则降级提示仍可参考输出（具体文案另定）。
