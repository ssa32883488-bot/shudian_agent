# 学灵伴 · 技术介绍（评委版）

> **作品名称**：学灵伴（数电单学科教育智能体）  
> **对应赛题**：2026 中国青年科技创新「揭榜挂帅」擂台赛 ·《面向一流学科建设的学科垂类大模型与创新应用开发》  
> **发榜单位**：科大讯飞  
> **锁定学科**：数字电子技术（高等教育单学科垂类）  
> **主场景**：助学（主）+ 管理控制台薄班级 / 题库经营（辅）  
> **工程本体**：`shudian_agent/`

---

## 1. 作品一句话

**学灵伴**是面向高校《数字电子技术》课程的伴随式助学智能体：以教材级知识库与题库为权威底座，以 LangGraph 工作流编排解题与答疑，以教材风格专业绘图工具把「讲清楚」落到「画得对」，并形成错题—学情—自适应练习与题库回流的可经营闭环。

去掉「大模型」三个字，它仍是一门课上的学伴：能搜到课本与题库、能画出门电路与时序图、能跟着学情加练，而不是一个通用聊天窗口。

## 2. 为何做这一门课

### 2.1 学科痛点（真实、可演示）

| 痛点          | 课堂表现                            | 通用 Chat 为何不够                  |
| ----------- | ------------------------------- | ----------------------------- |
| **图比文更难**   | 卡诺图、时序波、状态图、74/555 设计电路是作业与考试主干 | 纯文本描述学生不理解； SVG/ASCII 不符合教材规范 |
| **答案可信度模糊** | 学生需要「对不对、依据是什么」                 | 无校本教材溯源，无题库权威分级               |
| **自学断点多**   | 拍照搜题、整卷拆解、错题复盘、按薄弱点加练           | 无会话状态、无学情、无练习闭环               |
| **内容难经营**   | 新题不断涌入，教师/助教需沉淀到题库              | 无回流审核与班级学情视图                  |

### 2.2 场景定位

| 赛题场景   | 本作品覆盖                                      |
| ------ | ------------------------------------------ |
| **助学** | 自由问答（文/图/文档）、解题讲题、专业出图、错题本、学情画像、自适应练习      |
| **助教** | 管理控制台：题库 CRUD、未命中题回流审核、班级码、班级学情分析与 Word 导出 |
| **助研** | 本期不作为主叙事                                   |

## 3. 系统架构

### 3.1 总体分层

```
┌─────────────────────────────────────────────────────────┐
│  展示层   Vue 3 + Vite + Element Plus + KaTeX / ECharts │
│           学生端 · 管理控制台                             │
├─────────────────────────────────────────────────────────┤
│  接入层   Nginx（静态资源 + /api 反代）                    │
├─────────────────────────────────────────────────────────┤
│  业务层   FastAPI + LangGraph / LangChain                 │
│           感知 → 规划/决策 → 编排调工具 → 护栏与 Trace    │
├─────────────────────────────────────────────────────────┤
│  数据层   PostgreSQL/SQLite · ChromaDB · 知识图谱(Neo4j/  │
│           JSON 兜底) · MinIO(教材插图) · Redis(预留)      │
└─────────────────────────────────────────────────────────┘
```

### 3.2 运行时四层（Agent）

| 层           | 职责                                   | 典型产出                    |
| ----------- | ------------------------------------ | ----------------------- |
| **感知**      | 文本 / 图片 OCR / docx·pdf·ppt → 题面与题量粗估 | `question_text`、来源、多题信号 |
| **规划 / 推理** | 统一决策者：意图路由、计划、工具结果回判；自研回环 ≤3         | 意图、`plan.steps`、终判      |
| **编排**      | 按计划调度工具与子工作流；State / Checkpointer    | 检索、绘图、记忆读写              |
| **护栏与可观测**  | 迭代上限、断路器；学生步骤条 + 管理端完整 Trace         | 可审计轨迹                   |

短任务走 **ReAct**（不强制人机确认）；长任务 / 整卷走 **Plan-and-Execute + HITL**（气泡内确认计划后串行续跑，单回合原子题上限 5）。

### 3.3 技术选型摘要

| 能力        | 选型                                                        |
| --------- | --------------------------------------------------------- |
| 前端        | Vue 3.5、Pinia、Vue Router、Axios、KaTeX、markdown-it、ECharts  |
| 后端与编排     | FastAPI、LangGraph、LangChain Core                          |
| 大模型 / 多模态 | OpenAI 兼容 API（LLM + 识图 OCR）                               |
| 检索底座      | 本地 BGE-M3 Embedding + bge-reranker 精排 + ChromaDB          |
| 知识图谱      | 校本 JSON 图谱（前置关系 / 测点关系）；可选同步 Neo4j                        |
| 专业出图      | 统一 `draw_with_workflow`：Skill 规范 → IR → 校验重试 → 确定性引擎出 SVG |
| 部署        | Docker Compose 全量；另提供精简版（Nginx + FastAPI + SQLite）便于云上演示  |

## 4. 核心能力与学习闭环

### 4.1 学生端

| 能力        | 说明                                        |
| --------- | ----------------------------------------- |
| **自由问答**  | 自然语言发起；支持图文与常见课件附件；短/长双模式路由               |
| **解题与讲题** | 题库软召回 + 智能匹配 → 命中给权威解答；未命中 AI 现解并标注「仅供参考」 |
| **专业绘图**  | 按题意调用教材级图类（见 §5.2），图文混排呈现                 |
| **错题本**   | 增删改查、导入导出，承接练习与答疑沉淀                       |
| **学情总览**  | 个人画像（定时批跑 + 手动刷新）                         |
| **自适应练习** | 按学情薄弱点抽题加练                                |
| **知识图谱**  | 可视化浏览概念关系与学习路径                            |

### 4.2 管理控制台

| 域   | 能力                             |
| --- | ------------------------------ |
| 题库  | CRUD；经营校本默认题与回流新题              |
| 回流  | 学生未命中题库 → 解答后入待审队列 → 管理员审核通过入库 |
| 班级  | 班级码、成员管理                       |
| 学情  | 班级维度分析、Word 导出                 |
| 可观测 | Agent Trace（匹配分、工具步、熔断原因等）     |
| 配置  | 账号策略、回流模式等                     |

### 4.3 主闭环（可演示故事线）

```
拍照/文本/整卷文件
    → 感知与意图路由
    → 题库检索 + 匹配
         ├─ 命中 → 权威答案（可溯源）
         └─ 未命中 → AI 解题（参考标注）→ 权威校验 → 回流待审
    → 需要出图则走绘图工作流（校验 ≤3）
    → 写入会话 / 错题 / 学情
    → 管理员审核回流 → 题库自生长
```

## 5. 相对通用对话产品的技术差异化

### 5.1 知识权威与可追溯（对齐功能点 03、04）

- **教材 canonical 切块**（按章 ch01–ch08）入库 Chroma，回答可挂载课本片段与插图。  
- **题库双通道**：结构化业务库 + 向量召回；命中结果按权威交付，AI 自研结果强制参考标注。  
- **知识图谱**：`PRE_REQUISITE_OF` / `TESTS` 等关系支撑前置推荐与练习选题，而非百科式闲聊。  
- **回流人工门禁**：未审核内容不自动升格为「权威答案」。

### 5.2 教材级专业绘图工作流（内容质量与复杂求解的核心亮点）

统一门面 `draw_with_workflow`：大模型按 Skill/Spec 生成结构化 IR → 校验与有限重试 → **确定性渲染引擎**出 SVG（避免「自由发挥乱画」）。

已覆盖的主要图类包括：

| 图类                              | 典型用途                                       |
| ------------------------------- | ------------------------------------------ |
| 逻辑符号图 `logic_dag`               | 门级逻辑、表达式实现（netlistsvg + 教材皮肤）              |
| 时序波形 `timing_wave`              | 多信号高低电平时间轴                                 |
| 状态转换图 `state_machine`           | FSM / 次态分析                                 |
| 真值表 / 带圈卡诺图                     | 组合逻辑化简与功能表                                 |
| 七段数码管 / 特性曲线                    | 显示译码与 VTC 示意                               |
| `msi_design` | 74 MSI、555、CMOS、DAC/ADC 等设计电路（逻辑先行 + Digital） |

分层策略（Tier）：规则死、必须正确的图走确定性工具；结构多变、需理解题意的图走「规范驱动 + 校验」；高频窄格式图可走小模型专驱（路线预留）。这使数电「又要画又要算」的作业类型可被稳定支撑。

### 5.3 复杂任务编排与人机协同（对齐功能点 02、07）

- **意图路由 + 安全拦截**：先判断是否数电相关、短答还是长计划。  
- **Plan + HITL**：整卷/多题先列清单、用户确认后执行，避免一次跑飞。  
- **工具集**：题库检索、多路 RAG 重排、图谱查询、绘图族、学情与长期记忆读写。  
- **护栏**：最大迭代、熔断与 Trace，保证演示与试用可解释、可打断。

### 5.4 个性化与自适应（对齐功能点 08）

错题本 + 聚合画像 + 自适应练习；长期记忆工具支持跨会话偏好与薄弱点；班级学情服务教师侧「看见共性问题」。

### 5.5 BYOK 与部署友好

用户可在客户端填写自有 API Key，本机调用优先用户 Key，**不上服务器持久化**；未填 Key 时可用平台默认（文件类任务按产品约定要求用户 Key）。支持 Docker 一键部署与精简云上部署，便于评委复现 Demo。

## 6. 知识工程与数据资产

| 资产          | 内容要点                                                  |
| ----------- | ----------------------------------------------------- |
| 教材知识        | 阎石体系数电章节结构的 canonical 文本块；插图对象存储                      |
| 向量库         | `textbook_chunks`、`question_bank` 等 Chroma Collection |
| 默认题库        | 章末习题与例题规模灌库（量级约两百余题级习题 + 例题），可继续扩展                    |
| 知识图谱        | `knowledge_graph_v0.2` 等 JSON；支持路径查询与可选 Neo4j 同步      |
| 绘图资产        | Skill 文档、IR Schema、金标样例与回归验收                          |
| Prompt / 路由 | 导师系统提示、意图识别与双模式路由定稿文档                                 |

知识工程原则：**宁深勿宽**——只做数电，不做跨学科百科；权威来自校本教材与题库，而非模型「自信」。

## 9. 部署与复现（供评委 / 答辩）

**全量 Docker（推荐演示）：**

```bash
cd shudian_agent/docker
cp ../backend/.env.example ../backend/.env   # 配置 API Key 等
docker compose up --build
```

- 前端：`http://localhost:8080`  
- 后端：`http://localhost:8000`  
- 样例管理员账号见 `docker/README.md`  

**本地前端开发：** `frontend/` 下 `npm install && npm run dev`（默认代理后端 `:8000`）。

**精简云上：** 见 `docs/DEPLOY-阿里云精简.md`（Nginx + FastAPI + SQLite），适合公网 Demo。

离线数据准备顺序（教材图 → canonical 入库 → 图谱 → 题库）见 `data/README.md`。

## 10. 诚实边界与后续迭代

**竞赛提交边界**

- 主打助学深度 + 管理台题库/班级学情；**不承诺**正式统考判分与考务全流程。  
- 大模型调用依赖配置的兼容 API；专业绘图覆盖已验收图类，极罕见拓扑仍可能降级为文字说明。

**可继续增强（迭代计划口径）**

- 按章「课程制」系统学模块（进度状态机 + 掌握度门禁）  
- 更大规模班级试用与效果对比数据  
- 窄域图类小模型专驱以降本  
- 与学校认证 / 教务系统的轻量对接

## 11. 总结

学灵伴把「学科垂类大模型 + 智能体」落到一门具体的硬核工科课上：**用知识库保证可信，用工作流保证能做完复杂题，用专业绘图保证数电能讲明白，用学情与回流保证越用越贴校本。**

它回答赛题的方式不是「做一个什么都会聊的助手」，而是：**在《数字电子技术》这一垂类里，做成一个可部署、可审计、可经营的伴随式学伴。**
