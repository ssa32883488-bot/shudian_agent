## P0 · 演示主路径（必须能完整走通）

| # | 条目 | 验收标准 |
|---|------|----------|
| 1 | ★ 自由问答（ReAct）稳定演示 | 搜题/解题/引用可讲清；错题可写入 |
| 2 | ★ 学情画像 + 错题本 | 薄弱点可见；错题可导出 |
| 3 | ★ 自适应练习 | 按学情抽题 → 作答反馈 → 错题回流 |
| 4 | ★ 管理端题库 + 回流审核 | 增删题目；待审通过后入库可被练习抽到 |
