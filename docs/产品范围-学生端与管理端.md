# 产品范围（现行）· 学生端 + 管理控制台

> **生效**：2026-09-08（修订）。  
> 权威补充：`定稿-管理控制台与双模式HITL-BYOK.md`、`架构定稿-运行时分层.md`、`架构定稿-决策者状态与记忆Schema.md`。  
> 与旧「砍掉一切教师能力」表述冲突时，**以本节「薄教师并入管理控制台」为准**。

---

## 一句话

面向数字电子技术的 **助学智能体**：学生端个性化学习与问答；**管理控制台**经营题库，并用**班级码**做薄班级管理与班级学情分析。  
**不做**组卷、统考、收卷、判卷改判、考务 Agent。

---

## 账号

| 角色 | 注册/登录字段 | 校验 |
|------|----------------|------|
| 学生 | 昵称、手机号、班级码（可选） | 手机号 11 位，**无短信** |
| 教师管理员 | 昵称、手机号 | 同上 |

- 教师管理员可：**创建班级、生成班级码、班级管理、班级学情数据分析**。  
- 学生可以班级码加入班级（注册时或之后）。

---

## 学生端

| 能力 | 说明 |
|------|------|
| 自由问答 | 感知文/图/docx·pdf·ppt（先读懂再路由）；**仅大模型拆题列清单**（失败则整段一条、不按规则拆）；短 ReAct / 长 Plan；气泡内确认；子任务串行续跑；**浏览器 IndexedDB 全量保存会话历史** |
| 学情总览 | 个人画像；03:00 批跑 + 手动更新 |
| 错题本 | 增删改查 / 导入导出 |
| 自适应练习 | 按学情抽题加练 |

**不支持**：上传 Excel。

**BYOK**：用户填写 Key 后本机调用一律用用户 Key；Key **不上我们服务器持久化**；未填 Key 时图文可用平台默认；文件任务需用户 Key。详见定稿 BYOK 节。

---

## 管理控制台（原管理端 + 薄教师）

| 域 | 能力 |
|----|------|
| 内容 | 题库 CRUD；**回流审核**（学生未命中题库→解答后待审→管理员通过入库，含题干文字/原图+答案） |
| 班级 | 班级码、成员、班级学情—数据分析；学情可 **Word 导出** |
| 配置 | 账号策略、回流模式等系统配置 |
| 可观测 | Agent trace（P1；无泄露对话隐私给无关方） |

**明确不做**：组卷 → 发布 → 收卷 → 判卷 → 考试报告；考务悬浮球；**校本大纲裁剪**（学生端「大纲梳理」意图保留）。

---

## Agent 运行要点（学生问答）

- 单回合原子题上限 **5**；超限拆分并支持续跑。  
- 路由节点：`intent_router` 意图判定 + 安全拦截；长任务才拆题清单，短任务直达 ReAct。详见 `提示词-意图识别与智能路由.md`。  
- `plan_execute` **必须 HITL**（气泡内计划确认，可文字确认）。  
- 短任务不强制 HITL、不展示拆题清单。  
- Plan 进行中旁路答疑不关闭任务模式。

## 评审叙事

主场景 = 助学问答（含整卷/文件的计划模式 + HITL）+ 个人学情 + 练习错题。  
管理控制台 = 题库可经营 + 班级码班级 + 班级学情分析。不承诺正式考试判分系统。
