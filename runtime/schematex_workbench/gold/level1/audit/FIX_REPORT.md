## 2. 按类变更说明

### 2.1 组合逻辑走线（C01/C02/C05）
- **根因：** 多信号共用竖槽；总线横穿非门；分接竖轨缺段导致结点悬空。
- **改法：** 总线止于非门前；非门挂总线下方；字面量/反相分轨；与门前统一进线柱。

### 2.2 课本门级保真（L06）
- **根因：** 用显式 NOT+NAND 代替课本全 NAND，版式不符。
- **改法：** 入线直接用 B′/C′/A′；G3/G4 并脚作非；标注 G1–G7。

### 2.3 PLA（L05）与交叉（L02）
- L05：积项竖轨独立，或门左柱进线，禁止横穿门体。
- L02：A 竖落改到 AND3 右侧通道，避免穿门。

### 2.4 MSI / 标签（C08/C10/L07）
- C10：2Y 连续走线。
- C08：课本式使能名 S1/S′2/S′3。
- L07：IR 输入名与课本一致为 C′。

### 2.5 时序（F05–F10）
- 互补时钟、边沿/异步脚、符号类型（JK vs T）、输出级门型、串出 D_O 等按课本补齐或纠正。
